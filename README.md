# 홈트 AI 플래너 (Home Workout AI Planner)

AI 맞춤형 홈 트레이닝 운동 플래너 웹 & 모바일 애플리케이션입니다.

## 🔗 배포 사이트
- **GitHub Pages**: [https://bagjinwon0121-spec.github.io/jinwon0822/](https://bagjinwon0121-spec.github.io/jinwon0822/)

## 🚀 주요 기능
- **오늘의 루틴 추천**: AI 기반 맞춤 운동 루틴 생성
- **부위별 운동 탐색**: 가슴, 등, 하체, 어깨, 팔, 복근 등 타겟 운동
- **운동 타이머 & 트래커**: 세트별 타이머, 휴식 시간 카운트, 세트 기록
- **운동 기록 관리**: 날짜별 운동 히스토리 및 통계
- **보유 기구 설정**: 맨몸, 덤벨, 밴드, 턱걸이봉 등 환경별 맞춤 루틴

## 🛠 기술 스택
- **Framework**: React Native (Web), Expo SDK 57
- **Language**: TypeScript
- **Icons**: Lucide React Native, Expo Vector Icons
- **Deployment**: GitHub Pages, GitHub Actions

## 💻 로컬 실행 방법
```bash
# 패키지 설치
npm install

# 웹 개발 서버 실행
npm run web

# 웹 정적 번들 빌드 (/docs 배포용)
npm run build:web
```
